System Architecture and Quant Data Invariants

5/5 unit tests passing (buffer-first Binance sync)

1. Buffer-First WebSocket Sync

Opens combined Binance @depth@100ms streams first, buffers deltas, hydrates REST snapshots, and verifies U <= lastUpdateId + 1 <= u with zero missed updates.

2. In-Memory L2 Order Book

Applies incremental level updates and zero-qty deletes, guards against crossed books (best_bid >= best_ask), and computes microprice, OBI (L1/L5/L10), and VWAP slippage.

3. Bi-Temporal Zstd Parquet

Persists dual-timestamped records via PyArrow (event_time_ms vs knowledge_time_ms) so late historical backfills never leak into earlier point-in-time backtests.

4. Cross-Feed Drift Auditor

Compares live WS book state against independent REST depth snapshots, tracking mid, bid, and ask drift in bps, sequence gaps, and rolling 5-sigma return outliers.
